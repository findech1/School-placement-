# School-placement-


Develop a pseudo code for a program that accepts a candidate's score in a national examination,
gender, and age as input. Based on these details, the program should determine the appropriate
school placement for the candidate according to the following criteria:
School Placement Categories:
1. National Schools – For candidates with scores between 400 and 500 (inclusive).
2. Extra County Schools – For candidates with scores between 350 and 399 (inclusive).
3. County Schools – For candidates with scores between 250 and 349 (inclusive).
4. Special Schools – For candidates who:
o Have special needs (such as vision impairment, speech impairment, or other
physical challenges).
o Have a minimum score of 250.
o Are placed in special schools designated for their gender (boys to boys' special
schools, girls to girls' special schools).
5. Candidates who do not meet the requirements for secondary school placement (i.e., those
scoring below 250 and not qualifying for special schools) should be directed to either:
o A vocational training course, or
o Retaking the national examination.
Additional Guidelines:
 The pseudo code should prompt for input on whether the candidate has special needs
(Yes/No).
 Ensure the program validates whether the age falls within an acceptable range (e.g., 12–
18 years). If not, an appropriate message should be displayed, and the process should
terminate.
 The program should determine and display the school category the candidate qualifies
for, indicating whether it is a boys' or girls' school. If the candidate does not qualify for
any secondary school, the program should provide guidance on alternative options.
Task:
Design a structured pseudo code that correctly implements the placement logic, ensuring clarity
in input handling, processing, and output generation. Use appropriate control structures to
achieve the desired outcomes.
